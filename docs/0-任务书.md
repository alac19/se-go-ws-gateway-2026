## 一、任务背景

在实时 Web 应用（如直播弹幕、在线客服、金融行情推送、多人协作）中，WebSocket 已成为服务端主动推送数据的标准全双工协议。然而，生产环境直接暴露 WebSocket 服务需解决连接管理、心跳保活、消息路由、优雅关闭等通用问题。

本项目旨在使用 **Go + Gin + gorilla/websocket** 构建一款轻量级、高并发的 WebSocket 网关，作为业务后端与前端长连接之间的统一流量入口，支持连接管理、消息推送、心跳保活、优雅启停、监控指标等核心能力。

---

## 二、任务目标

- 支持 WebSocket 长连接的接入、注册、注销与心跳保活
- 提供全服广播、房间广播、单播三种消息推送模式
- 支持优雅启停（信号捕获 + 宽限期 + 资源清理）
- 集成 Prometheus 监控指标与结构化日志
- 支持配置文件（`config.toml`）+ 环境变量覆盖
- 通过 Docker 容器化部署，镜像大小 ≤ 50MB

---

## 三、主要功能

- **WebSocket 接入**：`/ws` 端点，支持 `clientId` 和 `roomId` 参数校验
- **连接管理器**：基于 `sync.Map` 的连接池，支持注册/注销/查询/遍历
- **房间管理器**：基于 `map` + `RWMutex` 的房间成员管理
- **消息路由**：全服广播、房间广播、单播，非阻塞 `select` 发送
- **心跳保活**：Ping/Pong 控制帧，支持配置间隔和超时
- **HTTP REST API**：`/api/broadcast`、`/api/room/:roomId/broadcast`、`/api/client/:clientId/send`、`/api/stats`
- **限流防护**：基于 IP 的令牌桶限流
- **优雅退出**：SIGINT/SIGTERM 信号捕获 + 宽限期 + 连接清理
- **监控指标**：Prometheus 指标暴露（连接数、消息收发量等）
- **结构化日志**：`slog` JSON 格式日志
- **健康检查**：`/health` 端点
- **容器化部署**：Docker + Docker Compose，多阶段构建
