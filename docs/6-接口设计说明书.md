## 一、引言

### 1.1 文档目的
本文档定义 WebSocket 实时推送网关对外提供的 HTTP REST API 及 WebSocket 接入接口，包括请求方法、路径、参数、响应格式及错误码，供前端客户端或业务后端调用方参考。

### 1.2 适用范围
本文档适用于网关服务的开发、测试及对接阶段。REST API 响应数据格式为 JSON，WebSocket 消息格式为纯文本（TextMessage）。

## 二、外部接口

### 2.1 WebSocket 接入

**接口描述**：客户端通过 WebSocket 协议连接到网关，建立全双工长连接。连接建立后，网关负责管理连接生命周期并接收上行消息（当前版本暂不处理上行），同时支持服务端主动推送下行消息。

- **请求方法**：`GET`
- **请求路径**：`/ws`
- **请求参数**：

  | 参数 | 类型 | 必填 | 说明 |
  |------|------|------|------|
  | `clientId` | string | 是 | 客户端唯一标识，由调用方生成并传入 |
  | `roomId` | string | 是 | 房间 ID，标识客户端所属分组 |

- **协议升级**：HTTP → WebSocket（状态码 `101 Switching Protocols`）

- **响应成功**：
  - 协议升级成功，进入 WebSocket 全双工通信模式
  - 服务端定期发送 Ping 帧进行心跳检测（当前 MVP 阶段暂未启用）

- **错误响应**：
  - `400 Bad Request`：`clientId` 或 `roomId` 为空或格式无效，服务端直接关闭连接
  - `500 Internal Server Error`：WebSocket 协议升级失败（例如请求头缺少 Upgrade 字段）

- **JavaScript 接入示例**：
  ```javascript
  const ws = new WebSocket("ws://localhost:8080/ws?clientId=test001&roomId=room1");
  ws.onopen = () => console.log("连接已建立");
  ws.onmessage = (e) => console.log("收到消息:", e.data);
  ws.onclose = () => console.log("连接已关闭");
  ```

### 2.2 全服广播

**接口描述**：向当前网关所有在线 WebSocket 客户端广播消息。业务后端通过此接口推送全局通知、系统公告等。

- **请求方法**：`POST`
- **请求路径**：`/api/broadcast`
- **请求头**：`Content-Type: application/json`
- **请求体**：

  ```json
  {
    "type": "text",
    "data": "这是一条全服广播消息",
    "timestamp": 1770451200000
  }
  ```

- **响应成功（200 OK）**：

  ```json
  {
    "code": 0,
    "status": "success",
    "data": null
  }
  ```

- **错误响应**：
  - `500 Internal Server Error`：服务内部错误，消息分发失败

---

### 2.3 房间广播

**接口描述**：向指定房间内所有在线客户端广播消息。适用于直播弹幕、在线课堂、游戏对局等按房间隔离的场景。

- **请求方法**：`POST`
- **请求路径**：`/api/room/:roomId/broadcast`
- **请求头**：`Content-Type: application/json`
- **路径参数**：

  | 参数 | 类型 | 必填 | 说明 |
  |------|------|------|------|
  | `roomId` | string | 是 | 目标房间 ID |

- **请求体**：

  ```json
  {
    "type": "text",
    "data": "这是一条房间内广播消息",
    "timestamp": 1770451200000
  }
  ```

- **响应成功（200 OK）**：

  ```json
  {
    "code": 0,
    "status": "success",
    "data": null
  }
  ```

- **错误响应**：
  - `404 Not Found`：指定房间不存在
  - `500 Internal Server Error`：服务内部错误

---

### 2.4 单播推送

**接口描述**：向指定的单个客户端发送消息。适用于点对点通知，如私信提醒、任务状态变更等。

- **请求方法**：`POST`
- **请求路径**：`/api/client/:clientId/send`
- **请求头**：`Content-Type: application/json`
- **路径参数**：

  | 参数 | 类型 | 必填 | 说明 |
  |------|------|------|------|
  | `clientId` | string | 是 | 目标客户端唯一标识 |

- **请求体**：

  ```json
  {
    "type": "text",
    "data": "这是一条私信消息",
    "timestamp": 1770451200000
  }
  ```

- **响应成功（200 OK）**：

  ```json
  {
    "code": 0,
    "status": "success",
    "data": null
  }
  ```

- **错误响应**：
  - `404 Not Found`：目标客户端离线或不存在
  - `500 Internal Server Error`：服务内部错误

---

### 2.5 连接统计

**接口描述**：查询当前网关的在线连接统计信息，包括总连接数等。用于监控网关健康状态。

- **请求方法**：`GET`
- **请求路径**：`/api/stats`
- **请求参数**：无
- **响应成功（200 OK）**：

  ```json
  {
    "code": 0,
    "status": "success",
    "data": {
      "online_connections": 128
    }
  }
  ```

- **错误响应**：
  - `500 Internal Server Error`：服务内部错误

---

### 2.6 Prometheus 监控指标（附加）

**接口描述**：暴露 Prometheus 格式的监控指标，供运维监控系统采集。

- **请求方法**：`GET`
- **请求路径**：`/metrics`
- **请求参数**：无
- **响应成功（200 OK）**：`Content-Type: text/plain; version=0.0.4`
- **暴露指标**：

  | 指标名 | 类型 | 标签 | 说明 |
  |--------|------|------|------|
  | `ws_gateway_msg_send_total` | Counter | `msg_type`（single/room/broadcast） | 消息发送总次数 |
  | `ws_gateway_msg_send_fail_total` | Counter | `reason` | 消息发送失败次数 |
  | `ws_gateway_online_conn` | Gauge | 无 | 当前在线连接数 |

## 三、WebSocket 通信协议

### 3.1 连接生命周期

```
客户端                          网关
  |                              |
  |-- GET /ws?clientId&roomId -->|
  |<-- 101 Switching Protocols --|
  |                              |
  |<-- (服务端推送消息) -----------|
  |-- (上行消息，当前版本忽略) -->|
  |                              |
  |<-- Ping (可选，未来启用) -----|
  |-- Pong (可选) -------------->|
  |                              |
  |-- (连接关闭) --------------->|
  |<-- 注销确认 -----------------|
```

### 3.2 消息格式

- **下行消息**（服务端 → 客户端）：服务端以 WebSocket TextMessage 帧推送 UTF-8 编码的 JSON 字符串，结构如下：
  ```json
  {
    "type": "text",
    "data": "消息内容",
    "timestamp": 1770451200000
  }
  ```
- **上行消息**（客户端 → 服务端）：当前 MVP 阶段服务端不对上行消息做业务处理，仅用于检测连接存活。

### 3.3 心跳保活（规划中）

- 服务端以可配置间隔（默认 30s）发送 Ping 帧
- 客户端须在可配置超时时间（默认 60s）内回复 Pong 帧
- 超时未响应则服务端主动关闭连接并触发注销流程

## 四、错误码说明

| HTTP 状态码 | 业务含义 | 说明 |
|-------------|----------|------|
| `200 OK` | 请求成功 | 正常返回业务数据 |
| `400 Bad Request` | 请求参数错误 | `clientId`/`roomId` 为空或格式无效 |
| `404 Not Found` | 资源不存在 | 房间或客户端不存在 |
| `429 Too Many Requests` | 触发限流 | 请求频率超过阈值（规划中） |
| `500 Internal Server Error` | 服务内部错误 | 请查看服务端日志定位原因 |
