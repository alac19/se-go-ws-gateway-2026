# **Go轻量级WebSocket网关 – 用户手册**

---

> **项目名称**：se-go-ws-gateway-2026
>
> **版本**：v1.0
>
> **日期**：2026-08-09


## 一、概述

本手册面向使用 WebSocket 网关的业务开发者与运维人员，帮助你快速完成网关的启动、配置、部署与日常操作。

**核心功能**：
- WebSocket 长连接接入与管理（支持 `clientId` 和 `roomId` 参数）
- 三种消息推送方式：全服广播、房间广播、单播
- 心跳保活、限流防护、优雅退出
- Prometheus 监控指标暴露


## 二、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Go | 1.26.4+ | 本地运行需要 |
| Docker | 24.0+ | 容器化部署需要 |
| Docker Compose | 2.20+ | 容器编排需要 |


## 三、快速启动

### 3.1 本地运行

```bash
# 克隆项目
git clone https://github.com/alac19/se-go-ws-gateway-2026.git
cd se-go-ws-gateway-2026

# 启动服务
go run cmd/gateway/main.go
```

服务默认监听 `8080` 端口。

### 3.2 容器化部署

```bash
# 启动所有服务（网关 + Prometheus）
docker-compose up -d

# 查看运行状态
docker-compose ps

# 查看日志
docker-compose logs -f gateway

# 停止服务
docker-compose down
```

### 3.3 验证服务是否正常

```bash
curl http://localhost:8080/health
```

预期输出：`{"status":"ok"}`


## 四、配置说明

配置文件位于 `configs/config.toml`，所有关键参数均可调整。

### 4.1 完整配置项

```toml
[server]
port = 8080                        # 服务监听端口

[websocket]
read_buffer_size = 1024            # 读缓冲区大小（字节）
write_buffer_size = 1024           # 写缓冲区大小（字节）
read_deadline_seconds = 60         # 读超时（秒）
write_deadline_seconds = 10        # 写超时（秒）
control_write_timeout_seconds = 1  # 控制帧写入超时（秒）

[heartbeat]
ping_interval_seconds = 30         # Ping 帧发送间隔（秒）
pong_wait_seconds = 60             # 等待 Pong 响应的超时（秒）
ping_write_timeout_seconds = 10    # Ping 帧写入超时（秒）

[channel]
send_buffer_size = 256             # 每个连接的发送通道缓冲区大小
register_buffer_size = 256         # 注册通道缓冲区大小
unregister_buffer_size = 256       # 注销通道缓冲区大小

[ratelimit]
every_seconds = 12                 # 令牌生成间隔（秒）
burst = 5                          # 令牌桶容量

[graceful_shutdown]
timeout_seconds = 5                # 优雅退出宽限期（秒）

[log]
level = "error"                     # 日志级别：debug / info / warn / error
file_path = "logs/gateway.log"     # 日志文件路径（为空则只输出控制台）
```

### 4.2 环境变量覆盖

以下环境变量可覆盖配置文件的对应值：

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `WS_PORT` | 服务监听端口 | 8080 |
| `WS_PING_INTERVAL` | Ping 帧发送间隔（秒） | 30 |
| `WS_PONG_WAIT` | Pong 响应超时（秒） | 60 |
| `WS_RATELIMIT_INTERVAL` | 令牌生成间隔（秒） | 12 |
| `WS_BURST` | 令牌桶容量 | 5 |
| `WS_SHUTDOWN_TIMEOUT` | 优雅退出宽限期（秒） | 5 |

```bash
# 示例：通过环境变量覆盖端口
export WS_PORT=9090
go run cmd/gateway/main.go
```

### 4.3 日志级别建议

| 环境 | 推荐级别 | 说明 |
|------|----------|------|
| 开发/测试 | `info` | 输出完整运行信息，便于调试 |
| 生产环境 | `error` | 仅输出错误日志，避免日志 I/O 影响性能 |


## 五、WebSocket 接入

### 5.1 连接地址

```
ws://localhost:8080/ws?clientId={clientId}&roomId={roomId}
```

### 5.2 参数说明

| 参数 | 类型 | 必填 | 格式要求 |
|------|------|------|----------|
| `clientId`、`roomId` | string | 是 | 仅允许 `a-zA-Z0-9_-` | 是 | 仅允许 `a-zA-Z0-9_-` |

### 5.3 连接示例

**使用 wscat 工具（Linux）**：

```bash
wscat -c "ws://localhost:8080/ws?clientId=test&roomId=room1"
```

连接成功后显示：`Connected (press CTRL+C to quit)`

**浏览器控制台**：

```javascript
const ws = new WebSocket("ws://localhost:8080/ws?clientId=test&roomId=room1");
ws.onopen = function() { console.log("✅ 连接已建立"); };
ws.onclose = function(event) {
    console.log("❌ 连接已关闭");
    console.log("状态码:", event.code);
    console.log("关闭原因:", event.reason);
};
ws.onerror = function(error) { console.error("⚠️ 错误:", error); };
```

### 5.4 关闭状态码说明

| 状态码 | 含义 |
|--------|------|
| `1000` | 正常关闭 |
| `1001` | 服务正在关闭（优雅退出） |
| `4000` | 参数缺失（缺少 clientId 或 roomId） |
| `4001` | 参数格式无效（含非法字符） |
| `4002` | clientId 已存在（重复连接被拒绝） |

### 5.5 心跳保活

- 服务端每 30 秒（可配置）发送一次 Ping 帧
- 客户端须在 60 秒（可配置）内回复 Pong 帧
- 超时未响应则服务端主动关闭连接


## 六、消息推送 API

所有 API 返回统一格式：

```json
{
  "code": 0,           // 0=成功，非0=错误码
  "status": "success", // success / error
  "data": null         // 成功时返回数据，失败时返回错误信息
}
```

### 6.1 全服广播

向所有在线客户端发送消息。

```bash
curl -X POST http://localhost:8080/api/broadcast \
  -H "Content-Type: application/json" \
  -d '{"type":"text","data":"hello all"}'
```

### 6.2 房间广播

向指定房间内的所有客户端发送消息。

```bash
curl -X POST "http://localhost:8080/api/room/room1/broadcast" \
  -H "Content-Type: application/json" \
  -d '{"type":"text","data":"Hello room1"}'
```

**响应示例（房间不存在时）**：

```json
{"code":404,"status":"error","error":"目标房间不存在"}
```

### 6.3 单播

向指定 clientId 的客户端发送消息。

```bash
curl -X POST http://localhost:8080/api/client/test1/send \
  -H "Content-Type: application/json" \
  -d '{"type":"text","data":"private message"}'
```

**响应示例（客户端离线时）**：

```json
{"code":404,"status":"error","error":"目标客户端离线或不存在"}
```

### 6.4 连接统计

查看当前在线连接数、各房间连接分布、服务运行时长。

```bash
curl http://localhost:8080/api/stats
```

**响应示例**：

```json
{
  "code": 0,
  "status": "success",
  "data": {
    "online_connections": 3,
    "all_rooms_connections_stats": {
      "room1": 2,
      "room2": 1
    },
    "gateway_server_initial_time": 3600
  }
}
```

### 6.5 健康检查

```bash
curl http://localhost:8080/health
```

**响应**：
```json
{"status":"ok"}
```

### 6.6 Prometheus 监控指标

访问 `http://localhost:8080/metrics` 获取：

| 指标名称 | 类型 | 说明 |
|----------|------|------|
| `ws_active_connections` | Gauge | 当前在线连接数 |
| `ws_gateway_msg_sent_total` | Counter | 消息发送总量 |
| `ws_gateway_msg_send_fail_total` | Counter | 消息发送失败数 |
| `ws_connection_events_total` | Counter | 连接事件总数 |

## 八、常见问题排查

### Q1：连接被拒绝，状态码 4000

**原因**：URL 缺少 `clientId` 或 `roomId` 参数。
**解决**：确保 WebSocket URL 包含完整参数：`?clientId=xxx&roomId=xxx`。

### Q2：连接被拒绝，状态码 4001

**原因**：参数包含非法字符。
**解决**：仅使用字母、数字、下划线、短横线。

### Q3：连接被拒绝，状态码 4002

**原因**：`clientId` 已被占用。
**解决**：使用唯一 `clientId`，或先断开旧连接。

### Q4：服务启动后立即退出

**可能原因**：
- 配置文件格式错误
- 日志目录无写入权限
- 端口被占用

**排查**：
```bash
# 检查配置文件
cat configs/config.toml

# 创建日志目录
mkdir -p logs

# 检查端口占用
netstat -tlnp | grep 8080
```

### Q5：Docker 容器健康检查失败

**排查**：
```bash
# 查看容器状态
docker-compose ps

# 查看容器日志
docker logs ws-gateway
```

### Q6：高并发下性能下降

**检查**：
1. 日志级别是否为 `info`（建议改为 `error`）
2. 是否触发限流（检查 `ratelimit` 配置）
3. 系统资源是否充足（CPU/内存/文件描述符）

### Q7：如何查看当前在线连接数？

```bash
curl http://localhost:8080/api/stats
```
