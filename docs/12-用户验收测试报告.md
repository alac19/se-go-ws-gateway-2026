## 一、引言

本报告总结了 Go 轻量级 WebSocket 网关的用户验收测试（UAT）结果。测试由用户代表参与执行，旨在验证系统是否满足业务需求、功能规格和性能预期，确保其可交付生产环境使用。

### 3.2 性能测试结果

按照验收计划中的性能用例（PT-01 ~ PT-06），使用自定义 `loadtest` 和 `hey` 工具进行测试，结果如下：

| 编号 | 测试项 | 实测结果 | 通过标准 | 状态 |
| ---- | ------ | -------- | -------- | ---- |
| PT-01 | 连接建立性能（1000 并发） | 建立时间 0.33s，成功率 100% | < 5s，≥ 99.9% | ✔ PASS |
| PT-02 | 广播延迟（2000 并发） | P99 39.01ms，送达率 100% | < 50ms，≥ 99.9% | ✔ PASS |
| PT-03 | 广播延迟（5000 并发） | P99 59.38ms，送达率 100% | < 80ms（极限验证），≥ 99.9% | ✔ PASS |
| PT-04 | 混合负载（2000 并发） | P99 31.41ms，错误率 0% | < 50ms，错误率 0% | ✔ PASS |
| PT-05 | HTTP 接口吞吐量 | QPS 50,260，P99 15.6ms，错误率 0% | ≥ 10,000，< 50ms，< 1% | ✔ PASS |
| PT-06 | 长时间稳定性（30 分钟） | 60 次广播 100% 成功，无内存泄漏 | 无泄漏，无中断，成功率 100% | ✔ PASS |

**性能结论**：系统在各并发级别下均达到或超过预期性能指标，错误率为 0，响应延迟满足验收标准。长时间运行无内存泄漏，连接稳定。

> **说明**：PT-05（吞吐量测试）旨在测量网关在不引入外部限制条件下的最大处理能力。限流器作为独立的安全防护组件，其功能已在 FT-16 中独立验证通过。因此在 PT-05 执行期间，限流器被临时禁用以排除对吞吐量结果的干扰。测试完成后限流器已恢复。

### 3.3 资源使用情况

在 PT-06（长时间稳定性测试，1000 连接，30 分钟）期间，通过任务管理器监测系统资源：

| 指标 | 观测值 | 结论 |
| ---- | ------ | ---- |
| **网关进程内存** | 稳定在 30 MB 左右 | 无内存增长趋势 |
| **网关进程 CPU** | 空闲时近 0%，广播触发时瞬时升高后回落 | 无异常波动 |
| **系统总内存** | 稳定在 58%~63% | 无持续增长 |
| **Heap Profile（pprof）** | `inuse_space` 仅 15.77 MB | 无堆内存泄漏 |

测试表明，网关进程内存占用极低，长时间运行无内存泄漏，具备优秀的轻量级特性，适合部署在资源受限的环境中。

## 五、测试结论

**正式通过验收**

系统满足以下验收标准：

- **功能完整**：所有功能用例 FT-01 ~ FT-21 100% 通过。
- **性能达标**：
  - 2000 并发下 P99 延迟 39.01ms（< 50ms），消息送达率 100%。
  - HTTP 接口 QPS 50,260（≥ 10,000），错误率 0%。
  - 长时间运行无内存泄漏，连接稳定。
- **安全合规**：限流、参数校验、重复连接拒绝均按预期生效。

**建议**：生产环境推荐部署在 Linux 服务器上以获得最佳性能，同时根据需要调整限流阈值和日志级别。
